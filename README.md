# ITSR System

ITSR System is a web-based IT service request system developed during my internship. The system helps manage user requests, staff tasks, departments, and support forms.

## Features

- User login
- Admin dashboard
- Staff management
- Department management
- IT service request form
- Request tracking
- Email testing function

## Technologies Used

- PHP
- MySQL / SQL Database
- HTML
- CSS
- JavaScript
- Composer
